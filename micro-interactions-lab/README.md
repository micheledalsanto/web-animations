# Micro-Interactions Lab

Fifty UI motion patterns built with HTML, CSS and vanilla JavaScript.

## Features

- 50 working interactions across five balanced categories
- category filters and per-card replay
- complete integration panel on every card, with copyable HTML, CSS and JavaScript
- mouse, pointer, focus and keyboard input
- semantic controls and synchronized ARIA state
- responsive layout and reduced-motion fallback
- no JavaScript dependency or build process

## Files

- `index.html` — accessible component markup
- `styles.css` — layout, visual tokens and numbered animation sections
- `script.js` — filters, complete source-code integration panels and numbered controllers

The animation numbers match across all three files. See the [integration guide](../docs/integration-guides.md) for extraction and production guidance.
